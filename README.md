# Rock Paper Scissors

A simple command-line Rock Paper Scissors game written in Python. Play against the computer and keep playing as many rounds as you like.

## Features

- Play against a computer opponent that picks randomly
- Input validation, so typos and extra spaces or capital letters are handled
- Replay option after every round

## Requirements

- Python 3.6 or newer (no extra libraries needed)

## How to run

1. Clone the repository:
```
   git clone https://github.com/YOUR-USERNAME/rock-paper-scissors.git
```
2. Go into the project folder:
```
   cd rock-paper-scissors
```
3. Run the game:
```
   python main.py
```

## How to play

1. Type `rock`, `paper`, or `scissors` when prompted.
2. The computer's choice is shown and the winner is announced.
3. Type `yes` to play again, or anything else to quit.

## Rules

- Rock beats scissors
- Scissors beats paper
- Paper beats rock
- Same choice is a draw
